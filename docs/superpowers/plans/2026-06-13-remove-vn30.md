# Remove VN30 Market Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xóa hoàn toàn VN30 market khỏi hệ thống — crawler, prediction, bot, API, frontend, DB.

**Architecture:** Big Bang — tất cả layers (Python, Go, Frontend, DB) trong một lần, theo thứ tự Python → Go → Frontend → DB. Python compile check chạy sau mỗi task Python. Go `go build ./...` chạy sau khi xong Go. Frontend `npm run build` chạy sau khi xong Frontend.

**Tech Stack:** Python 3.12 (APScheduler, SQLAlchemy, gRPC), Go 1.21 (GORM, gRPC), React + TypeScript (Vite), MySQL 8.0, protobuf.
